01 / Research directions

From cloud infrastructure to intelligent collaboration.

Eight connected directions spanning adaptive infrastructure, distributed intelligence, trust, software quality, and human-aware computing.

01↗

Scheduling · orchestration · scaling

Cloud & Serverless Computing

Resource scheduling, orchestration, auto-scaling, migration, and performance-aware execution for cloud-native and serverless systems.

02↗

Cloud-to-edge continuum

Edge Computing

Adaptive resource management and computation across distributed edge and cloud environments.

03↗

Distributed intelligence

Federated Learning

Collaborative learning approaches for distributed environments where data and computation remain decentralized.

04↗

LLMs · distributed training

Federated Learning for LLMs

Federated approaches for training and adapting large language models across distributed participants and infrastructure.

05↗

Trust · uncertainty · decisions

Computational Trust

Models of trust, distrust, uncertainty, and decision-making in software and socio-computational environments.

06↗

Maintainability · code quality

Automatic Software Refactoring

Automated techniques for identifying and improving code and architectural quality, including learning-based refactoring and anti-pattern detection.

07↗

People + computation

Socio-computational Systems

Models and mechanisms for systems where software behavior and human or social dynamics interact.

08↗

Adaptive software

Context-aware Computing

Software systems that sense changing conditions and adapt their behavior to contextual information.
