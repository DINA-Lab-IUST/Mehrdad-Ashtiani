01 / Research directions

From distributed
infrastructure to software intelligence.

The established research profile is grounded in cloud resource management, computational trust, socio-computational systems, context-aware computing, and automatic software refactoring. DINA Lab extends that trajectory toward edge and federated intelligence.

Established track01

Distributed infrastructure

Cloud, serverless & adaptive resource management

Scheduling, orchestration, auto-scaling, scientific workflows, microservices, function scheduling, and resource-aware execution across cloud and serverless environments.

SchedulingOrchestrationAuto-scalingFaaS
DINA direction02

Cloud-edge continuum

Edge computing & federated intelligence

Emerging lab work explores how computation and learning can move closer to data while preserving coordination across distributed environments.

EdgeFederated LearningFederated LLMs
Established track03

Trustworthy systems

Computational trust

Models of trust, distrust, uncertainty, propagation, evolution, and decision-making for social and distributed computational environments.

Established track04

Software quality

Automatic refactoring, repair & software evolution

Automated identification and correction of code quality issues using search, probabilistic, reinforcement-learning, and deep-learning techniques.

Official profile05

Human + computational systems

Socio-computational systems

Computational models for systems in which social behavior, trust, collective decisions, and technical mechanisms interact.

Established track06

Adaptive software

Context-aware & self-adaptive computing

Systems that observe workload or environmental context and adapt execution, scaling, scheduling, or behavior accordingly.

Publication thread07

Resource coordination

Scientific workflows & distributed scheduling

Deadline-, budget-, and resource-aware scheduling of multi-stage workloads in cloud and workflow-as-a-service environments.

Research + industry08

Interactive systems

Intelligent game systems & quantitative game analysis

Research and applied work spanning game analytics, free-to-play monetization, procedural or learned level evaluation, and software production in the game ecosystem.

Distributed Cyber Attack Simulator (DCAS)

A distributed simulation framework for modeling cyber attacks and evaluating network security measures. The project used High-Level Architecture (HLA) and a Portico-based runtime to support distributed interactive simulation.
